# Issue tracker: Jira

Issues and specs for this repo live in Jira project `SD` on
https://cjamesfoust.atlassian.net.

## Conventions

- Create issues in project `SD` using the connected Atlassian Jira integration.
- Always validate the project and issue type before creating a ticket.
- Reference tickets by Jira key, such as `SD-123`.
- Search issues with JQL.
- Add discussion and implementation updates as Jira comments.
- Use Jira statuses for workflow state and the configured triage labels for triage state.

## When a skill says "publish to the issue tracker"

Create a Jira issue in project `SD`.

## When a skill says "fetch the relevant ticket"

Fetch the referenced Jira issue by its key.
